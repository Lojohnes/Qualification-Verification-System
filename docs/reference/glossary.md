# Glossary

Last updated: 2026-08-10

| Term | Definition |
|---|---|
| AQVP | Academic Qualification Verification Platform. |
| Verification Platform | Module that verifies qualifications through QR code, certificate upload, or authoritative lookup. |
| Certificate Generation Module | Capability for authorized institutions to create qualification records and generate certificates. |
| Read-Only Organization | Client that can verify qualifications but cannot create or modify authoritative records. |
| Read & Write Organization | Verified issuing institution that can create and maintain qualifications within its authorized scope. |
| Super Admin | Highest-level platform administrator. |
| System Admin | Platform administrator responsible for day-to-day client onboarding and support. |
| IT Admin | Client organization technical administrator. |
| HR Manager | Client operational user who performs qualification verification. |
| Director | Client oversight user. |
| Qualification Holder | Person who received a qualification. |
| Qualification Record | Authoritative server-side record of an academic qualification. |
| Certificate | Digital or printable representation of a qualification. |
| Security Identifier | Unique cryptographically secure identifier associated with a qualification. |
| QR Record | QR-linked verification reference associated with a qualification. |
| Verification Request | An attempt to verify a presented qualification or certificate. |
| Verification Result | Outcome of a verification request. |
| RBAC | Role-Based Access Control. |
| JWT | JSON Web Token used for stateless authentication. |
| DTO | Data Transfer Object used for API payloads. |
| Flyway | Database migration tool. |
| MapStruct | Java annotation processor used for mapper generation. |
| Bounded Context | Module boundary owning a coherent part of the domain model. |
| Tenant | Isolated client organization boundary. |
| PII | Personally identifiable information. |
| CI/CD | Continuous Integration / Continuous Delivery. |
| Swagger / OpenAPI | API documentation and exploration tooling. |
